Idea generale

Le serie di Fourier descrivono funzioni periodiche come combinazioni di seni e coseni. Per una funzione con periodo \(2\pi\), una forma comune e:

\[ f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty} \left(a_n\cos nx + b_n\sin nx\right). \]

Coefficienti

I coefficienti misurano quanto ogni modo armonico contribuisce alla funzione. In notazione reale:

\[ a_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\cos(nx)\,dx, \quad b_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\sin(nx)\,dx. \]

Esempio computazionale

Un semplice script puo approssimare un'onda quadra sommando armoniche dispari.

import numpy as np

x = np.linspace(-np.pi, np.pi, 1000)
approx = np.zeros_like(x)
for n in range(1, 20, 2):
    approx += (4 / np.pi) * np.sin(n * x) / n

Perche e utile

Le serie di Fourier collegano analisi matematica e fisica: compaiono nello studio delle onde, della conduzione del calore, dei segnali e dei metodi numerici.
